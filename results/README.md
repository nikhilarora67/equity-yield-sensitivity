# Generated results

The research scripts write CSV tables and figures to this directory. Generated outputs are not included in the starter repository because they depend on the exact equity universe and the market-data snapshot used when the analysis is run.

Key files produced by the screening stage include:

- `all_sensitivity_estimates.csv`
- `top_negative_sensitivity.csv`
- `top_positive_sensitivity.csv`
- `sector_summary.csv`
- `spy_yield_sensitivity_by_cadence.csv`
- `spy_beta_by_cadence.csv`
- `yield_effect_by_cadence.csv`

The walk-forward stage additionally produces performance summaries, yearly attribution, basket histories, sector mix, and cumulative-P&L figures.

The latest published README includes a concise snapshot of the September 2026 run so that the headline findings are visible without requiring a local rerun.
